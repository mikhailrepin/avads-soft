# AVADS Soft

Корпоративный веб-сайт компании АВАДС СОФТ с каталогом программных продуктов для промышленной автоматизации.

## О компании

ООО «АВАДС СОФТ» - российский разработчик программных решений для автоматизации, диспетчеризации и учёта на промышленных объектах, в ЖКХ, системах автоматизации зданий и умных домов. Компания интегрирует собственные цифровые продукты с АСУТП, АСУЭ, АСКУЭ, АСТУЭ, АСУЗ (BMS) и занимается импортозамещением в ключевых IT секторах.

История компании началась в 2021 году, основана бывшими сотрудниками компаний "ИнСАТ" и "МПС СОФТ".

## Технические особенности веб-сайта

- Построен на Astro.js
- Использует Tailwind CSS для стилизации
- Адаптивный дизайн
- Используется сборка с помощью Vite
- Динамические данные о продуктах загружаются из `src/data/prodSoft.json`
- Автоматизация обновления ссылок на загружаемые файлы

## Разработка

### Установка

```bash
npm install
```

### Запуск сервера разработки

```bash
npm run dev
```

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр сборки

```bash
npm run preview
```

## Автоматизация

### Обновление ссылок на файлы загрузки

В проекте реализовано автоматическое обновление ссылок на загружаемые файлы в `src/data/prodSoft.json`. Скрипт `scripts/update-downloads.js` автоматически запускается при запуске `npm run dev` и `npm run build`.

При добавлении новых файлов в директории `/public/downloads/tsdb`, `/public/downloads/sar-expert` или `/public/downloads/opc-db` ссылки в prodSoft.json будут обновлены автоматически.

Дополнительная информация о скрипте доступна в [scripts/README.md](scripts/README.md).
