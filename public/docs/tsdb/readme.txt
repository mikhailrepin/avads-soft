     1. ТРЕБОВАНИЯ К АППАРАТУРЕ
   
     Для  нормальной  работы АВАДС Сервера архивирования требуется 
ЭВМ,  построенная  на   базе   процессоров  Intel x86  или  AMD64,  
допускающих установку 64-разрядных операционных систем:
     - Windows 8 и выше; 
     - Astra Linux 1.6 и выше; 
     - Alt Linux: Альт Рабочая станция 9 и выше; 
     - Linux Ubuntu 20.04 и выше, 
     - Linux Debian 10 и выше, 
     - другие сброки Linux, подобные перечисленным.
     Для  установки и запуска Сервера архивирования  тредуется  не 
менее 30 Мбайт дисковой  памяти  и  не  менее 8 Гбайт  оперативной 
памяти. 


     2. Запуск Сервера архивирования

     Под  ОС Windows  АВАДС Сервер архивирования  запускается  как 
сервис при старте  операционной системы. Поэтому  после завершения 
инсталляции следует перезагрузить компьютер.
     Для  установки  Сервера архивирования  под  ОС Linux  следует
скачать в терминале запустить установочный скрипт install.sh
     Для запуска под ОС Linux следует выполнить  следующую команду
в терминале "sudo systemctl start avads_sa_service", для остановки
"sudo systemctl stop avads_sa_service"

     Сервер  архивирования  АВАДС запускается в Windows как сервис
при  старте  системы.  После  завершения  установки  рекомендуется
перезагрузить компьютер.

     Для  установки Сервера  архивирования под ОС Linux скачайте и
запустите  установочный  скрипт install.sh. Для  запуска выполните
команду   "sudo systemctl start avads_sa_service",  для  остановки
"sudo systemctl stop avads_sa_service".
