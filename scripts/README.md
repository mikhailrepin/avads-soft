# Скрипты автоматизации

## Скрипт обновления ссылок на файлы загрузки (update-downloads.js)

Скрипт предназначен для автоматического обновления ссылок на файлы в `src/data/prodSoft.json` на основе фактических файлов, находящихся в директориях `/public/downloads/`.

### Принцип работы

1. Скрипт сканирует директории загрузок для каждого продукта (`tsdb`, `sar-expert`, `opc-db`)
2. Находит самый новый файл для каждой платформы (Windows и Linux) на основе шаблонов имен файлов
3. Обновляет соответствующие ссылки в файле `prodSoft.json`

### Использование

Скрипт автоматически запускается при выполнении команд:

- `npm run dev` - перед запуском сервера разработки
- `npm run build` - перед сборкой проекта

Также можно запустить скрипт отдельно:

```bash
npm run update-downloads
```

или напрямую:

```bash
node scripts/update-downloads.js
```

### Добавление поддержки нового продукта

Для добавления поддержки нового продукта необходимо добавить шаблоны имен файлов в объект `FILE_PATTERNS` в скрипте:

```javascript
const FILE_PATTERNS = {
  // Существующие продукты
  "имя-нового-продукта": {
    windows: /шаблон-для-windows\.exe$/i,
    linux: /шаблон-для-linux\.tar\.gz$/i,
  },
};
```

### Расширение функциональности

При необходимости скрипт можно расширить для:

- Поддержки других ОС (например, macOS)
- Обновления не только demo-версий, но и других типов загрузок
- Интеграции с CI/CD системами
