Мы выпустили новую версию [Сервер архивирования 1.1.0](/all-products/tsdb). В данной версии был улучшен и доработан функционал приложения, были исправлены найденные ошибки, а также оптимизирована работа некоторых функций.

**Основные доработки**

В протоколе AVADS-TCP добавлены следующие команды:

- Добавлена команда 35, которая возвращает список последних ошибок при выполнении команд 29 (групповое добавление записей)
- Добавлена команда запроса текущего (последнего полученного) значения временного ряда. Код команды равен 33
- Для стадии авторизации добавлена команда восстановления сессии после обрыва соединения. Код команды равен 2. Параметром команды является ключ сессии
- Добавлена команда получения информации о временном ряде по его числовому идентификатору. Код команды равен 34

Протокол AVADS-WEB был так же расширен:

- Добавлена команда **getSeriesById**, позволяющая получать информацию о временном ряде по его идентификатору

**_Важные изменения_**

- Команды протокола AVADS-WEB в пределах одной сессии теперь выполняются асинхронно
- Добавлен параметр **TimeOut** для запросов к базе. По умолчанию этот параметр равен 2 минуты. Если время исполнения превысит установленное время запрос будет отменен
- В протоколе AVADS-TCP на стадии авторизации команда логина (код команды равен 1) в случае успеха теперь возвращает ключ сессии
- В протоколе AVADS-TCP в командах 11,12 параметр Ttime (задает тип представления времени) теперь соответствует типу byte
- Размер поля **Quality** в записи теперь составляет 4 байта (uint32). В протокол взаимодействия с Сервером архивирования внесены соответствующие изменения

**Внимание!** В связи с изменением размера поля Quality старые версии баз потеряли совместимость.

Подробнее ознакомиться со всеми возможностями Сервера архивирования можно на странице [продукта](/all-products/tsdb).

Для тестирования Сервера архивирования имеется [ДЕМО-версия](/downloads/#tsdb). У нее нет ограничений на число тегов и клиентов, но она работает не более 2 месяцев с момента инсталляции.
ДЕМО-версии собраны для операционных систем Windows и Linux на платформе X86.
